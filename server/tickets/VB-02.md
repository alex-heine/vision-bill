🎫 VB-02: Single Model Deep Dive Validation (Deep Test)

Goal: Once a promising model is identified (from Ticket 1), this script runs it against the entire dataset to collect specific data for manual review, such as tag suggestions and error patterns. This is the pre-implementation validation step.

```python
# script_single_model_validation.py

def deep_dive_analysis(target_model: str, data_dir: str = "./test_data/receipt/"):
    """Runs all receipts against one specific model to collect detailed logs."""
    print(f"\n--- Starting Deep Dive for {target_model} ---")
    all_results = []

    for receipt_path in get_all_image_paths(data_dir):
        try:
            analysis, ground_truth = run_single_receipt_test(get_model_interface(target_model), receipt_path)

            # 1. Collect Accuracy Metrics (Hit Rate)
            hit_rate = calculate_field_accuracy(analysis, ground_truth)

            # 2. Collect Tag Suggestions for Manual Review
            suggested_tags = analysis.get('tag_suggestions', {})

            all_results.append({
                'receipt': receipt_path,
                'hit_rate': hit_rate,
                'ai_tags': suggested_tags
            })
        except Exception as e:
            print(f"Failure at {receipt_path}: {e}")

    # Output Detailed CSV/JSON Log for Human Review
    save_to_log("deep_dive_report.json", all_results)
    return len(all_results)


if __name__ == "__main__":
    chosen_model = "llama3" # Model returned by Ticket 1
    deep_dive_analysis(chosen_model)
```
