🎫 AB-03: Tag Suggestion Profiling Script (Discovery Focus)

Goal: A highly focused script that ignores all receipt data except for the LLM's tag suggestions. It aggregates and profiles how often certain tags are suggested, helping define your initial taxonomy before coding.

```python
# script_tag_profiler.py

def profile_ai_tags(data_dir: str = "./test_data/receipt/"):
    """Runs a specialized test to extract and count all AI-generated tag suggestions."""
    print("--- Starting Tag Suggestion Profiling ---")
    all_suggestions = []

    for receipt_path in get_all_image_paths(data_dir):
        try:
            # Only need the LLM analysis here, not the ground truth yet
            analysis = run_single_receipt_test(get_model_interface("best-model"), receipt_path)

            if 'tag_suggestions' in analysis:
                tags = analysis['tag_suggestions']
                for key, value in tags.items():
                    all_suggestions.extend(value) # Combine existing and new lists
        except Exception as e:
            # Handle failure but continue profiling other receipts
            continue

    # Aggregate and Tally
    tally = Counter()
    for tag in all_suggestions:
        tally[tag] += 1

    print("\n--- TOP TAG SUGGESTIONS PROFILE ---")
    for tag, count in tally.most_common(20): # Display top 20 suggestions
        percentage = (count / len(all_suggestions)) * 100
        print(f"[{tag:<25}] Count: {count:>3} ({percentage:.1f}%)")

    save_to_log("tag_profile_report.json", tally)


if __name__ == "__main__":
    # This script identifies the best tags *before* we write the Tagging UI logic.
    profile_ai_tags()
```
