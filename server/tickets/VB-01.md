## 🏗️ ARCHITECTURAL PREREQUISITE (The Interface)
Before any of these scripts can run, we must define the contract that all services will follow. This is an Abstract Base Class (ABC) defining a generic service interface (`BaseServiceInterface`). Any specific API integration (like Ollama or a future cloud provider) must inherit from this class.

**Goal:** Ensure no single piece of business logic depends on the concrete implementation details (e.g., HTTP client).

## 🧪 TEST SCRIPT SET: Model & Data Validation Suite

The following scripts are designed to be run as independent, modular CLI tools. They assume a directory structure `./test_data/receipt/` containing image files (`*.jpg`) and corresponding ground-truth JSON files (`*.json`).

### 🎫 VB-01: Batch LLM Comparative Performance Test (Model Selection)

**Goal:** Systematically test all available models via the generic interface against a full dataset to determine which model provides the highest reliability. This is the initial "model selection" script.

```python
# script_batch_comparison.py

def run_full_llm_benchmark(data_dir: str = "./test_data/receipt/", models: list[str] = None):
    """Runs all available receipts against a model and calculates field hit rate."""
    print("--- Starting Batch LLM Benchmark ---")
    if not models:
        # Dynamically discover available models via the BaseServiceInterface
        models = ["llama3", "phi3"] # Placeholder for discovery logic

    results = []
    receipt_files = get_all_image_paths(data_dir)

    for model in models:
        model_runs = []
        print(f"\n[RUNNING] Testing Model: {model}")
        for receipt_path in receipt_files:
            try:
                # Use the Generic Interface to abstract the call
                analysis, ground_truth = run_single_receipt_test(
                    service=get_model_interface(model),
                    image_path=receipt_path,
                    expected_json=load_ground_truth(receipt_path)
                )
                hit_rate = calculate_field_accuracy(analysis, ground_truth)
                latency = measure_execution_time() # Implementation of time measurement
                model_runs.append({'hit': hit_rate, 'latency': latency})
            except Exception as e:
                print(f"Error processing {receipt_path}: {e}")

        # Aggregate results for the current model
        avg_accuracy = calculate_median(model_runs)
        results.append({'model': model, 'median_hit_rate': avg_accuracy})

    # Output Final Table and Recommendation
    report_summary(results)
    return get_best_performing_model(results)

def report_summary(data: list):
    """Prints the final performance table to stdout."""
    print("\n--- BENCHMARK FINAL REPORT ---")
    for entry in data:
        print(f"Model: {entry['model']:<15} | Median Hit Rate: {entry['median_hit_rate']:.2%} | Recommendation: {'BEST' if entry['model'] == get_best_performing_model(data) else 'SUB'} ")

if __name__ == "__main__":
    # This function will return the highest accuracy model name string.
    best_llm = run_full_llm_benchmark()
